# SPIN RHub 1.2

## Изменения

- Позиции прокрутки разделов, альбомов, исполнителей, папок, плейлистов и вкладок загрузок сохраняются на устройстве, включая полное закрытие приложения. Запоминаются до 160 последних экранов. В настройках восстанавливаются также раскрытые группы.
- Проверка новых стабильных версий при запуске и вручную в «Настройки → О приложении → Обновления».
- Список изменений релиза отображается в приложении.
- APK скачивается только после нажатия «Скачать». Есть прогресс, ожидание сети, повтор после ошибки и восстановление состояния системной загрузки после перезапуска приложения.
- После загрузки появляется «Установить». При необходимости Android предлагает разрешить установку из SPIN RHub. После выдачи разрешения следует вернуться и нажать «Установить» ещё раз.
- Перед установкой проверяются размер APK, имя пакета, версия, более высокий versionCode и прежний сертификат подписи. Если GitHub возвращает SHA-256, он также проверяется.

## GitHub Releases

Репозиторий: eravalk/SPIN-RHub. Стабильный релиз должен иметь тег `v1.3` или `1.3` (для следующей версии) и опубликованный файл `SPIN-RHub-1.3.apk`. Номер версии в APK должен совпадать с тегом, versionCode — быть больше 17. Все обновления подписываются прежним ключом SPIN Player New. Черновики и предварительные релизы не предлагаются. Если опубликованного APK нет, приложение сообщает, что релиз пока недоступен.

При подготовке 1.2 репозиторий был пуст; публикация GitHub Release в эту поставку не входит. Первый APK 1.2 устанавливается вручную поверх 1.1. Исходный приватный ключ и пароль не включаются в архив исходников.

## Проверка

- Android-сборка, D8, zipalign и подпись исходным ключом.
- Автоматические проверки сохранения позиций при смене разделов/альбомов и после моделируемого перезапуска; некорректного сохранённого состояния; явного начала скачивания, прогресса, повтора и кнопки установки.
- Проверки метаданных релиза: сравнение версий, точный HTTPS-адрес нужного репозитория, отклонение предварительных релизов и некорректного digest.
- Регрессии запуска, очереди и фаз анимации иглы.

Физическое Android-устройство недоступно: реальная загрузка через Android DownloadManager, установщик, разрешение неизвестных источников и поведение после принудительной остановки на Fold ещё не проверены. Headless Chromium в текущем окружении не запускается из-за запрета системного socket(); браузерная проверка интерфейса не засчитывается как пройденная.
