# SPIN RHub

Музыкальный плеер для Android с виниловой пластинкой, перемоткой иглой и поддержкой складных экранов.

## Установка и обновления

APK и полный архив исходников — в разделе [Releases](https://github.com/eravalk/SPIN-RHub/releases). Android 13 и новее, ARM64. Устанавливайте APK поверх предыдущей версии с пакетом `com.spinplayer.next`, без удаления приложения.

Плеер проверяет GitHub Releases. Обновление загружается только после нажатия «Скачать»; установку подтверждает системный установщик Android.

## 1.3.0.0

- Встроен подбор аудио через оригинальные модули spotDL 4.6.0 с резервным поиском YouTube Music; загрузка выполняется через yt-dlp.
- Добавлен публичный каталог Spotify: треки, альбомы и плейлисты. Spotify предоставляет метаданные; полное аудио подбирается на YouTube Music.
- Источники: YouTube, YouTube Music, Spotify, Яндекс Музыка и SoundCloud. Для полного доступа Яндекса требуется подключение аккаунта и права на запись; реализован MP3.
- Сохранение прокрутки между разделами и перезапусками.
- Четырёхкомпонентные версии: основная версия, значительное дополнение, исправления, малое срочное исправление.

Сборка, подпись и офлайн-проверки выполнены. Работа нового модуля spotDL на ARM64-устройстве и реальные сетевые сценарии новых источников ещё требуют проверки. Доступность записей зависит от сервиса, региона и прав аккаунта. Подробный отчёт и сценарии проверки на Fold: `RELEASE-1.3.0.0.md` и `tests/1.3.0.0-validation.json` в архиве исходников.
