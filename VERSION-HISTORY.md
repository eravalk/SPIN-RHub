# Нумерация SPIN RHub

Принята схема **основной выпуск.значительное дополнение.исправления.малый срочный фикс**.

Например, для 1.2.3.4:

| Тип следующего выпуска | Номер |
|---|---|
| Небольшой срочный фикс | 1.2.3.5 |
| Набор исправлений / обычная доработка | 1.2.4.0 |
| Значительная новая функция | 1.3.0.0 |
| Новый основной выпуск | 2.0.0.0 |

При увеличении компонента все компоненты справа обнуляются. Смена названия приложения не увеличивает первый компонент сама по себе. Нумерация до первого основного выпуска начинается с 0. Канал alpha/RC указывается отдельно от четырёх чисел.

## Переход

Текущая поставка переобозначена из 1.3 в **1.2.0.0**, Android versionCode увеличен с 18 до 19. Это изменение нумерации и упаковки, без заявления о готовности встроенного spotDL. Функции и ограничения прежней тестовой 1.3 сохраняются.

Новый номер записан внутри APK, на экране «О приложении», в имени файла и настройках сборки. Исторические APK и архивы сохраняют первоначальные встроенные номера; таблица выше задаёт их новые обозначения в истории и сохраняет возможность точно определить исходный файл.

Первый APK с новой нумерацией следует установить вручную поверх старой сборки. Старый уже установленный код проверки обновлений не знает соответствия 1.3 → 1.2.0.0. Android обновит пакет по возросшему versionCode и прежней подписи. Новая проверка понимает соответствие старых двухкомпонентных версий, а будущие релизы использует только с четырьмя компонентами.

Для GitHub релизов: тег `v1.2.0.1`, файл `SPIN-RHub-1.2.0.1.apk` (пример малого следующего фикса). Увеличивается также независимый Android versionCode.

## Единый источник номера

`version.properties` задаёт versionName и versionCode. Обе системы сборки и экран приложения используют эти значения. Команды из корня исходников:

```bash
python3 tools/version.py --bump hotfix
python3 tools/version.py --bump fix
python3 tools/version.py --bump feature
python3 tools/version.py --bump final
```

Каждая команда увеличивает выбранный компонент, обнуляет младшие и увеличивает Android versionCode на 1. Без параметров команда только синхронизирует номер интерфейса.

## 1.3.0.0 — расширение Spotify и интеграция spotDL

Новый выпуск, versionCode 20: оригинальные модули сопоставления spotDL 4.6.0, отдельный публичный каталог Spotify, пагинация альбомов/плейлистов и отдельные потоки поиска. Это существенное дополнение после 1.2.0.0, поэтому увеличен второй компонент и сброшены два последующих. Подробности и граница проверки: RELEASE-1.3.0.0.md.

## 1.4.0.0 — Liquid Glass и выбор стиля

Android versionCode 21. Первый работающий CD-интерфейс, кейс альбома/плейлиста, лазерная перемотка и отдельный пункт «Стиль приложения» в начале настроек. Статус: интеграционная сборка, требуется проверка на Fold. Подробности: RELEASE-1.4.0.0.md.
